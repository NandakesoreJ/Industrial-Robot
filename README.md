# Industrial Robot Arm – Fusion 360 CAD Project

![Robot Arm](images/full_robot.png)

## Overview
This project presents the CAD design of a multi-joint industrial robotic arm created using Autodesk Fusion 360.  
The model demonstrates mechanical assembly design, articulated joints, and a functional gripper mechanism.

The robot is designed using a modular approach where each component is modeled individually and later assembled to form the complete robotic manipulator.

---

## Features
- Multi-joint robotic arm structure  
- Articulated mechanical gripper  
- Modular CAD component design  
- Mechanical assembly relationships  
- Parametric modeling workflow
